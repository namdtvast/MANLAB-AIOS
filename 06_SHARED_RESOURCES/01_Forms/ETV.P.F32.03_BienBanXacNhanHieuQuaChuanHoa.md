## 4. HÀNH ĐỘNG CHUẨN HÓA *(ETV.P32 §6.7.3 — bắt buộc hoàn tất trước khi đóng sáng kiến)*

| # | Hành động | Áp dụng | Bằng chứng *(mã tài liệu, mã bản ghi)* | Ngày hoàn tất |
|---|---|---|---|---|
| 1 | Cập nhật thủ tục, quy trình, hướng dẫn (MP14) | ☐ Có ☐ Không áp dụng | | |
| 2 | Cập nhật, thay thế, thu hồi biểu mẫu (MP14) | ☐ Có ☐ Không áp dụng | | |
| 3 | Cập nhật phân quyền, cấu hình ManLab (MP28, MP35) | ☐ Có ☐ Không áp dụng | | |
| 4 | Đào tạo và xác nhận năng lực người dùng (MP03) | ☐ Có ☐ Không áp dụng | | |
| 5 | Cập nhật danh mục nền tảng, điểm tích hợp (MP35, MP37) | ☐ Có ☐ Không áp dụng | | |
| 6 | Cập nhật mức độ số hóa của quá trình *(thang 0–4)* | ☐ Có ☐ Không áp dụng | Từ mức ...... lên mức ...... | |
| 7 | Ghi nhận bài học kinh nghiệm (MP26) | ☐ Có ☐ Không áp dụng | | |
| 8 | Cập nhật hồ sơ rủi ro và cơ hội (MP01) | ☐ Có ☐ Không áp dụng | | |

> Chưa hoàn tất các hành động trên → sáng kiến **không được đóng**, hệ thống gắn cờ **Nợ quy trình**. Cờ tồn tại quá **60 ngày** → báo cáo LĐV.
> Sáng kiến **Không đạt** ở Mức 2, Mức 3 → **bắt buộc** lập bài học kinh nghiệm (MP26) trước khi đóng.
