### I.1. Đo lường và kiểm soát liên quan

| Mã sáng kiến | Chỉ số đo | Đường cơ sở *(giá trị – nguồn – kỳ đo)* | Chỉ tiêu hiệu quả | Cách đo lại | Phiếu thay đổi MP30 | Có dùng AI (MP29) | Nền tảng (MP35) | Mua sắm (MP06) |
|---|---|---|---|---|---|---|---|---|
| SK-........-........ | | | | | CR-.......-....... | ☐ Có ☐ Không | | ☐ Có ☐ Không |
| | | | | | | ☐ Có ☐ Không | | ☐ Có ☐ Không |

> Sáng kiến **không có đường cơ sở** hoặc chỉ tiêu không phải bằng số → **không được trình phê duyệt** (ETV.P32 §6.3.1 và Phụ lục IV).

### I.2. Mốc thời gian và kết quả

| Mã sáng kiến | Ngày sàng lọc | Ngày phê duyệt | Bắt đầu triển khai | Thí điểm từ – đến | Ngày đo lại | Kết luận hiệu quả *(Đạt / Đạt một phần / Không đạt)* | Ngày đóng | Cờ **Nợ quy trình** |
|---|---|---|---|---|---|---|---|---|
| SK-........-........ | | | | | | | | ☐ Có – từ ngày ...... |
| | | | | | | | | ☐ Có – từ ngày ...... |

**Cờ Nợ quy trình** = đã triển khai xong nhưng chưa hoàn tất hành động chuẩn hóa (ETV.P32 §6.7.3). Tồn tại quá **60 ngày** → báo cáo LĐV.
