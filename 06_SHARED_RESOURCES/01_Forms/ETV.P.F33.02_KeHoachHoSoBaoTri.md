|---|---|---|---|---|---|---|---|---|
| 1 | | | ☐ Nghiêm trọng (07 ngày) ☐ Cao (30) ☐ TB (90) ☐ Thấp | | | | | ☐ Đúng hạn ☐ **Quá hạn** |

> Mức **Nghiêm trọng**: nếu chưa vá được thì **bắt buộc** áp dụng biện pháp giảm thiểu tạm thời trong **48 giờ** và ghi vào bảng trên.
> Vá lỗi mức Nghiêm trọng **quá hạn** hoặc bảo trì quá **02 chu kỳ** → cảnh báo LĐV và **mở KPH** theo ETV.P13, số: ..............
