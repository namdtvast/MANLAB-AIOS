## PHẦN B — SÀNG LỌC *(QLCL và TCĐS điền)*

### B.1. Điều kiện cổng vào *(ETV.P32 §6.3.1 — thiếu bất kỳ điều kiện nào thì trả lại, không chấm điểm)*

| 2 | Xác định được **chủ sở hữu quá trình** và **chủ sở hữu dữ liệu** (MP27) | ☐ Đạt ☐ Không | |

### B.2. Chấm điểm *(thang 1–5, 5 là thuận lợi nhất)*

| Tiêu chí | Trọng số | Điểm | Điểm × trọng số | Nhận xét |
|---|---|---|---|---|
| Lợi ích và mức độ cấp thiết | 30% | | | |
| Mức độ phù hợp định hướng (MP25) | 20% | | | |
| Mức độ sẵn sàng dữ liệu và quá trình | 20% | | | |
| Chi phí và nguồn lực | 15% | | | |
| Rủi ro | 15% | | | |
| **Tổng hợp** | **100%** | | | |

> Điểm là **căn cứ kiến nghị**, không phải quyết định tự động. Kiến nghị **Không tiếp nhận** bắt buộc có nhận xét bằng lời.
