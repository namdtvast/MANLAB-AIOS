## PHẦN B — ĐỀ NGHỊ HIỆU CHỈNH DỮ LIỆU ĐÃ GHI NHẬN

> **Nguyên tắc bất biến:** dữ liệu đo thô và hồ sơ kỹ thuật **không được sửa trực tiếp, không ghi đè, không xóa**. Hiệu chỉnh bằng **bản ghi mới**, giữ nguyên giá trị cũ (ETV.P34 §6.3.1; ISO/IEC 17025 §7.5).

| Trường | Nội dung |
|---|---|
| Bản ghi, trường dữ liệu cần hiệu chỉnh | |
| **Giá trị trước** | |
| **Giá trị sau** | |
| Lý do hiệu chỉnh | |
| Bằng chứng đính kèm | |
| Người đề nghị — ngày | |
