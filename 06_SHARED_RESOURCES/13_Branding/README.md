## Quy tắc sử dụng

1. Luôn dùng 3 màu chính theo bảng trên, không tạo biến thể màu
2. Logo tối thiểu 2,1 cm (theo chiều ngang)
3. Giữ khoảng trắng tối thiểu xung quanh logo
4. Không xoay, biến dạng, hoặc thay đổi tỷ lệ logo
