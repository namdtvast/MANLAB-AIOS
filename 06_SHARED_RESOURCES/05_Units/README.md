# 05 — Units (Đơn vị đo & quy đổi)

> **Một câu:** viết đơn vị thế nào cho đúng và quy đổi giữa các đơn vị ra sao — để kết quả trên mọi chứng chỉ, báo cáo, màn hình đọc giống nhau.

**Hiện có:** chưa có file — mục dưới mô tả những gì sẽ đưa vào.

## Lưu gì ở đây

| Loại | Ví dụ |
|---|---|
| Bảng đơn vị SI và ký hiệu chuẩn | `m`, `kg`, `s`, `Pa`, `°C`, `mg/m³` — kèm cách viết đúng (khoảng trắng, chữ hoa/thường) |
| Bảng quy đổi | mmHg → Pa, bar → Pa, ppm ↔ mg/m³ (kèm điều kiện nhiệt độ, áp suất) |
| Quy tắc trình bày số liệu | chữ số có nghĩa, làm tròn, cách ghi kết quả kèm độ không đảm bảo đo |
| Danh mục đơn vị hợp lệ cho phần mềm | giá trị được phép chọn ở ô "đơn vị" trên module |

## Phép thử nhanh

> Nội dung này đúng với **mọi phép đo của mọi khách hàng**? → để ở đây. Chỉ đúng với một thiết bị hoặc một phép đo? → không phải chỗ này.

**Lưu ý:** Sửa bảng quy đổi ở đây → mọi nơi tra lại đều thống nhất. Đừng để mỗi quy trình một hệ số quy đổi riêng.
