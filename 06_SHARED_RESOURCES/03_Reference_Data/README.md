# 03 — Reference Data (Bảng tra & hằng số)

> **Một câu:** những con số **không đổi** mà nhiều phép đo, nhiều báo cáo cùng tra — hệ số, bảng tra, hằng số.

**Hiện có:** chưa có file — mục dưới mô tả những gì sẽ đưa vào.

## Lưu gì ở đây

| Loại | Ví dụ |
|---|---|
| Bảng tra thống kê dùng khi tính độ không đảm bảo đo | bảng hệ số phủ `k`, bảng phân phối t-Student theo bậc tự do |
| Hằng số vật lý, hằng số môi trường | gia tốc trọng trường, khối lượng riêng không khí ở điều kiện chuẩn |
| Bảng tra kỹ thuật dùng chung nhiều phương pháp | áp suất hơi bão hoà theo nhiệt độ, hệ số hiệu chỉnh |
| Danh mục đại lượng đo và ký hiệu | khối lượng `m`, áp suất `p`, lưu lượng `Q` |

Mỗi bảng phải ghi **nguồn** (tiêu chuẩn/ĐLVN/tài liệu nào, điều khoản nào) ngay trong file — bảng tra không có nguồn thì không dùng được để bảo vệ trước đoàn đánh giá.

## Phép thử nhanh

> Con số này **năm sau vẫn thế** và **nhiều phép đo cùng dùng**? → bảng tra, để ở đây. Đo xong mới có? → là kết quả, không để ở đây.

**Lưu ý:** Sửa một bảng tra → mọi phép tính dùng lại nó cập nhật theo. Đừng chép bảng vào từng quy trình kỹ thuật.
