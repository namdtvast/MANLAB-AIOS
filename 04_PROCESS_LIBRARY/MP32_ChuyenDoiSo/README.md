**Phân biệt với thủ tục lân cận:** ETV.P13 xử lý cái đã sai · **ETV.P32** làm tốt hơn cái đang đúng · ETV.P30 kiểm soát lúc thực sự thay đổi · ETV.P35 quản lý nền tảng số · ETV.P29 quản lý trí tuệ nhân tạo.
