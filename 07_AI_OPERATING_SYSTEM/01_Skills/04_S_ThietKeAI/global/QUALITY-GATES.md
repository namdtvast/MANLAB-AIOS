# Quality Gates

## QG-01 Nội dung
- [ ] Không thiếu nội dung bắt buộc.
- [ ] Không tự tạo dữ liệu hoặc tuyên bố.
- [ ] Thuật ngữ và dấu tiếng Việt chính xác.
- [ ] Nguồn/trích dẫn được giữ khi có.

## QG-02 Bố cục
- [ ] Có một trọng tâm chính.
- [ ] Phân cấp tiêu đề rõ.
- [ ] Không tràn/cắt/chồng chữ.
- [ ] Khoảng trắng hợp lý.

## QG-03 Thương hiệu
- [ ] Đúng logo do người dùng cung cấp.
- [ ] Đúng token màu, font và phong cách.
- [ ] Không kéo méo logo.

## QG-04 Accessibility
- [ ] Tương phản đủ tốt.
- [ ] Cỡ chữ phù hợp.
- [ ] Trạng thái không chỉ biểu thị bằng màu.
- [ ] HTML có semantic/label/keyboard focus khi áp dụng.

## QG-05 Dữ liệu kỹ thuật
- [ ] Có đơn vị đo.
- [ ] Có mốc thời gian/cập nhật.
- [ ] Có trạng thái chất lượng dữ liệu.
- [ ] Trục, ngưỡng, ký hiệu không gây hiểu sai.

## QG-06 Bàn giao
- [ ] Có file nguồn.
- [ ] Có file xuất bản.
- [ ] Có manifest.
- [ ] Ghi rõ điểm cần xác nhận.
