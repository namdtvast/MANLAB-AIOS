# Bảng định tuyến

| Yêu cầu | Skill chính | Skill kiểm tra kèm theo |
|---|---|---|
| Dashboard, form nghiệp vụ, portal | ui-ux-dashboard | accessibility-review, brand-compliance |
| Infographic, poster, quy trình một trang | infographic-etv | brand-compliance, design-review |
| Slide đào tạo, thuyết trình | slide-deck-etv | brand-compliance, design-review |
| Báo cáo, tài liệu PDF/Word | report-document | brand-compliance |
| Website/prototype HTML | web-prototype | accessibility-review, design-review |
| Mobile app | mobile-prototype | accessibility-review, design-review |
| Biểu đồ, trực quan dữ liệu | data-visualization | design-review |
| Đánh giá sản phẩm có sẵn | design-review | accessibility-review, brand-compliance |
| Xuất và đóng gói | export-delivery | design-review |

Nếu yêu cầu gồm nhiều loại sản phẩm, `design-router` lập kế hoạch và dùng một design system duy nhất cho toàn bộ bộ sản phẩm.
