# Quản trị ManLab/ETV

## Mục đích
Thiết kế quy chế, vai trò, phân quyền, kiểm soát thay đổi, trách nhiệm phê duyệt.

## Đối tượng
Nhóm ManLab/ETV — kỹ thuật viên, quản lý phòng thí nghiệm, người phụ trách QMS.

## Khi nào dùng
- Khi yêu cầu có từ khóa hoặc nội dung liên quan `governance`.
- Khi cần chuyển tri thức ManLab/ETV/DMC thành tài liệu, workflow, rule, code hoặc checklist.

## Đầu vào cần có
- Mục tiêu công việc.
- Tài liệu hoặc dữ liệu hiện có, nếu có.
- Phạm vi áp dụng: ETV, ManLab, DMC, KC4.0, khách hàng, phòng thí nghiệm.

## Cách làm
1. Đọc RULEBOOK của skill này.
2. Phân tích yêu cầu → tự chọn template phù hợp (SOP, BPMN, RBAC, checklist).
3. Xác định entity, vai trò, trạng thái, căn cứ ISO, rủi ro.
4. Tạo đầu ra theo template đã chọn.
5. Tự kiểm tra bằng CHECKLIST.

## Chuẩn ISO ưu tiên
- ISO/IEC 17025 — phòng thí nghiệm hiệu chuẩn & thử nghiệm (CHÍNH)
- ISO/IEC 42001 — quản trị AI
- ISO/IEC 27001 — an toàn thông tin

## Đầu ra ưu tiên
- **Quy trình / SOP** — mã hiệu, phiên bản, phê duyệt, phạm vi, trách nhiệm, trình tự, hồ sơ.
- Sơ đồ BPMN / workflow khi cần hình hóa luồng xử lý.
- Rule / phân quyền RBAC khi liên quan phần mềm.
- Checklist kiểm tra / audit.
- Gợi ý triển khai cho Claude Code nếu liên quan phần mềm.
